# pkzgui
pkzgui is a GUI application which can be used to view, and modify the proprietary package format for Beenox's Goliath Engine.

Supported Games
- Spider-Man Edge Of Time : X360

Supported Features
- Audio Playback
- Model and basic material viewing
- Texture Viewing and Replacing

Planned Features
- Audio Replacing
- Model Replacing
- Better Material Handling / Shaders
- Animation Playback & Importing
